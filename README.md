# One-Line Robot Wedding Vows

A tiny Python program (stdlib only) that writes one original funny robot
wedding vow to `/output/entry.txt` for the make.fun competition
[One-Line Robot Wedding Vows](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

Run it with `python3 main.py`. The output path can be overridden with the
`ENTRY_OUTPUT` environment variable (default `/output/entry.txt`).
